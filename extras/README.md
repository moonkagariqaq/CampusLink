# 登录后自动开启 Windows 热点

`CampusHotspotLogon.cs` 是独立小程序，在当前用户登录后运行，等待 CampusLink 认证，再调用 Windows 自带的移动热点接口。保留原热点名称和密码，不改动认证服务。

```powershell
./extras/BuildHotspot.ps1
```

构建后可手动运行根目录的 `CampusHotspotLogon.exe`，也可将它的快捷方式放进当前用户的启动文件夹。若使用登录计划任务，可选择“当前用户登录时”且不设置延迟；在电池供电时也想启动，需要取消任务的交流电源限制。

运行状态保存在 `%LOCALAPPDATA%\CampusLink\Hotspot\status.json`。程序最多等待四分钟，启动成功后退出，不常驻监控手机连接状态。因此不保证手机长时间锁屏后永不断连；无线网卡/手机省电与驱动需要独立排查。

目前自动选择网卡仍针对开发环境的 `100.2.*` 地址，其他校园网需要修改检测条件。此目录不包括未验证的服务自动热点升级方案。
